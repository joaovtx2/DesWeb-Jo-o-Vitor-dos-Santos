Projeto Web

Repositório criado para apresentação da atividade prática da disciplina de Desenvolvimento Web. O projeto consiste em uma estrutura web básica integrando HTML5, CSS3, JavaScript e PHP com PDO para conexão com banco de dados.

Estrutura do Projeto

DesWeb-Jo-o-Vitor-dos-Santos/ 
│ 
├── 1_index.html # Interface principal com marcação semântica e formulário 
├── 2_style.css # Estilização visual (Box Model e seletores) 
├── 3_script.js # Interatividade e manipulação do botão interativo 
├── 4_conexao.php # Script PHP de conexão segura com PDO └── readme.md # Documentação do repositório## Sobre o Projeto

Frontend:Interface estruturada em HTML5, estilizada com CSS3 (utilizando Box Model e seletores modernos) e dinamizada com JavaScript Vanilla para interatividade em tempo real.
Backend e Banco de Dados: Processamento de dados via PHP com PDO (PHP Data Objects), realizando a conexão segura com um banco de dados MySQL para o cadastro de informações.
